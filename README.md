# CER - Centro Esportivo de Referência

**CER** is a digital platform developed by the CER startup to democratize and expand access to sports in Recife, Pernambuco.

## 🚀 About the Project
The mission of CER is to leverage technology to map, register, and connect people to sporting environments, promoting community engagement and accessible physical activity for everyone.

## 🛠️ Tech Stack
* **Backend:** Python, Flask
* **Forms & Security:** Flask-WTF, WTForms, CSRF Protection
* **Templating:** Jinja2, HTML5
* **Version Control:** Git & GitHub

## ✨ Current Features
* Dynamic user registration system using Jinja2 loops for clean component rendering.
* Automated form field filtering and secure input validation (Email verification, Data Required checks).
* Structured modular architecture separating routes (`main.py`) and form definitions (`forms.py`).
